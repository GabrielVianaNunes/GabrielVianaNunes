# Architecture

## Branches

| Branch | Purpose |
|---|---|
| `main` | What the profile shows. Only updated from `develop` or from a hotfix |
| `develop` | Integration branch. Features merge here first |
| `feature/*` | One change each, created from `develop` |
| `output` | Files generated by GitHub Actions. Never edited by hand |

## Files

```
assets/               pixel art SVGs generated by scripts/build_assets.py
data/quotes.json      the quote list
scripts/              asset generator and quote picker
docs/wiki/            source of the wiki pages
.github/workflows/    weekly quote and 3D contribution workflows
```

## Data flow

1. A workflow runs on a schedule (weekly for quotes, daily for the 3D graph).
2. It builds an SVG and pushes it to the `output` branch.
3. The README loads the SVG from `raw.githubusercontent.com` on that branch.

Keeping generated files on `output` means `main` never receives bot commits.

## Known gotcha

GitHub caches images by file name. If a changed image does not update, rename the file. The footer was renamed to `footer-dusk.svg` for this reason.
